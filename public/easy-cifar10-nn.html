전체 흐름

1. 준비

CIFAR-10 이미지 50,000장(학습) + 10,000장(테스트)을 불러와 컴퓨터가 다루기 좋은 숫자 배열로 바꿈

테스트 이미지 1장을 받아 학습 이미지 5,000장과 픽셀 거리를 계산해 가장 가까운 1장의 라벨을 답
CIFAR-10이란?
32×32 크기 작은 컬러 사진 6만 장. 10개 클래스가 정해져 있어요: airplane, automobile, bird, cat, deer, dog, frog, horse, ship, truck. 학습용 50,000장 + 테스트용 10,000장으로 나뉘어 있습니다.

② 함수 — 입력을 받아 작업을 묶은 것

def로 시작합니다. "이 이름으로 부르면 이 일을 해라"를 정의해 놔요.

def say_hello(name):        # name 이라는 입력을 받아

③ 클래스 — 데이터+기능을 한 덩어리로

비슷한 것들을 만들어내는 설계도예요. 설계도(클래스)로 실제 사물(객체)을 찍어냅니다.

class Dog:
    def __init__(self, name):   # 처음 만들어질 때 한 번 실행
        self.name = name        # 이 강아지 객체에 이름을 저장

    def bark(self):               # 이 강아지가 할 수 있는 동작
        print(self.name + " 멍멍!")

d = Dog("바둑이")                  # 설계도로 강아지 한 마리 만들기
d.bark()                            # 바둑이 멍멍!
self가 뭐예요?
클래스 안의 함수에서 self는 "지금 그 동작을 하고 있는 본인"을 가리켜요. 위 코드에서 d.bark()를 부르면 그 안의 self는 d 본인입니다. self.name은 "내 이름표"라는 뜻이에요.

3데이터 로드 — CIFAR-10 가져오기

이 함수는 "이미지 5만 장을 컴퓨터가 다루기 좋은 큰 표로 정리해서 돌려주는" 일을 합니다.

def load_cifar10(train=True):
    """
    torchvision으로 CIFAR-10을 다운로드하고
    (N, 3072) serial 배열과 레이블 배열을 반환합니다.
    """
    dataset = torchvision.datasets.CIFAR10(
        root='.', train=train, download=False
    )

    data = dataset.data
    serials = np.concatenate([
        data[:, :, :, 0].reshape(-1, 1024),
        data[:, :, :, 1].reshape(-1, 1024),
        data[:, :, :, 2].reshape(-1, 1024),
    ], axis=1)

    labels = np.array(dataset.targets)

    return serials, labels


train_serials, train_labels = load_cifar10(train=True)
test_serials,  test_labels  = load_cifar10(train=False)

print(train_serials.shape)
# 결과 출력: (50000, 3072)

왜 굳이 1D로 펼칠까?

원본: (50000, 32, 32, 3)   — 4차원 (장수, 가로, 세로, 채널)
↓ R·G·B를 따로 펴서 옆에 붙이기
serial: (50000, 3072)   — 2차원 표 (장수, 픽셀 일렬)
R 10240~1023번
+
G 10241024~2047번
+
B 10242048~3071번
📏 비유 — 책을 줄세우기
이미지 한 장을 "3072개의 숫자가 일렬로 늘어선 한 줄"로 만들면, 두 이미지를 비교할 때 "줄과 줄의 차이"만 보면 돼서 계산이 훨씬 단순해져요. 이걸 serial(직렬화)이라고 부릅니다.
픽셀 값의 범위
각 픽셀은 0~255 사이 정수예요. 0이 가장 어둡고 255가 가장 밝아요. 컬러 사진은 R/G/B 각 채널마다 이 숫자가 따로 있어 32×32×3 = 3072개 숫자가 한 장을 표현합니다.

41D 배열을 다시 이미지로 되돌리기

위에서 펼쳐버린 줄을 사람이 볼 수 있는 사진으로 거꾸로 복원하는 함수입니다.

def serial2image(serial):
    """
    serial: (3072,) 배열 — R 1024개, G 1024개, B 1024개 순서
    각 채널을 (32, 32)로 reshape한 뒤 (32, 32, 3) 이미지로 합쳐 반환합니다.
    """
    red   = serial[:1024].reshape(32, 32)
    green = serial[1024:2048].reshape(32, 32)
    blue  = serial[2048:].reshape(32, 32)

    return np.stack([red, green, blue], axis=2)

6train / predict 인터페이스

본격 구현 전에, "학습"과 "예측"이라는 두 가지 동작의 모양만 먼저 정의해두는 단계예요. 머신러닝 코드는 보통 이 두 단어를 중심으로 짜입니다.

def train(images, labels):
    return Model(images, labels)


def predict(model, test_images):
    return model(test_images)
def train(images, labels): return Model(images, labels)
"학습 = Model 객체를 하나 만들어 돌려주는 것"이라 정의. 1-NN은 학습할 게 따로 없어서 그저 데이터를 그대로 모델에 담아두는 게 끝.
def predict(model, test_images): return model(test_images)
"예측 = 모델을 함수처럼 호출해서 결과를 받는 것"이라 정의. model(test_images)처럼 객체를 함수처럼 부르는 비결은 다음 절에서.
🍳 비유 — 요리사 채용
train은 도서관에 책을 잔뜩 넣어 새 사서를 한 명 만드는 일. predict는 그 사서에게 책을 들이밀며 "이게 뭔지 알려줘"라고 묻는 일이에요. 1-NN의 사서는 그냥 책 더미를 통째로 기억해 두는 게 학습입니다.

7Model 클래스 — 1-NN의 본체

이 페이지에서 가장 중요한 부분이에요. 차근차근 봅시다.

class Model:
    def __init__(self, images, labels):
        self.images = images
        self.labels = labels

    def __call__(self, test_images):
        return [self.predict(image) for image in test_images]

    def predict(self, image):
        num_images = self.images.shape[0]

        distances = np.abs(self.images - image).sum(axis=1)

        idx = np.argmin(distances)

        return self.labels[idx]

① __init__ — 모델이 만들어질 때 한 번

def __init__(self, images, labels):
Model(...)로 처음 만들어질 때 자동 실행되는 생성자.
self.images = images self.labels = labels
받은 학습 데이터를 이 모델 본인의 속성으로 저장. "다음에 필요할 때 또 꺼내쓸 수 있도록" 가지고 있는 것.

② __call__ — 객체를 함수처럼 부를 때

def __call__(self, test_images):
파이썬의 마법 메서드. model(...)처럼 모델을 함수처럼 부르면 이게 실행됨. 그래서 predict(model, X) 안에서 model(X)가 동작.
return [self.predict(image) for image in test_images]
리스트 컴프리헨션. "test_images 안에서 image를 하나씩 꺼내, 각각 self.predict(image)를 부른 결과를 모은 리스트". 즉 여러 장을 받아 하나씩 예측하고 리스트로 반환.
리스트 컴프리헨션 = 짧은 for 루프
[f(x) for x in xs] 는 아래와 똑같아요: 
result = []
for x in xs:
    result.append(f(x))

③ predict — 진짜 핵심!

def predict(self, image):
한 장의 테스트 이미지(image: 3072개 숫자가 든 1D 배열)를 받아 라벨 하나를 돌려줄 것.
num_images = self.images.shape[0]
학습 이미지의 개수를 구함. (실제 계산엔 안 쓰여요 — 이해/디버깅용)
distances = np.abs(self.images - image).sum(axis=1)
1-NN의 심장. 학습 이미지 전체와 테스트 이미지 1장의 L1 거리를 한 번에 계산. 결과는 길이 N짜리 거리 배열.
idx = np.argmin(distances)
거리 배열에서 가장 작은 값의 위치를 알려줌. = 가장 가까운 학습 이미지의 번호.
return self.labels[idx]
그 번호에 해당하는 라벨을 답으로 돌려줌. 끝!

거리 계산을 자세히

한 줄로 적혔지만 NumPy의 마법이 세 단계로 작동해요.

1
self.images - image
self.images는 (N, 3072), image는 (3072,). NumPy는 브로드캐스팅으로 두 모양을 맞춰 모든 학습 이미지에서 테스트 이미지를 자리마다 빼줌. 결과 (N, 3072).
2
np.abs(...)
뺀 결과의 부호를 떼고 크기만 남김. 픽셀이 얼마나 달랐는지 그 크기만 중요.
3
.sum(axis=1)
한 줄(이미지 1장)당 3072개 차이를 옆으로 다 더함. 한 장의 "총 픽셀 차이"가 한 숫자로 요약됨. 최종 (N,).
self.images (N, 3072)  −  image (3072,)
↓ 브로드캐스팅 + 절댓값
diff (N, 3072)
↓ axis=1 방향으로 sum
distances (N,)  — 각 학습 이미지까지의 L1 거리
브로드캐스팅 (broadcasting)
NumPy는 모양이 다른 두 배열을 빼/더할 때 작은 쪽을 자동으로 늘여서 맞춰줍니다. (N, 3072) − (3072,)는 작은 쪽을 N번 복제한 것처럼 동작해 한 번에 N장을 처리해줘요. for문 없이 빠릅니다.

L1 거리(맨해튼 거리)란?

두 이미지 A, B의 픽셀 차이의 절댓값 합입니다.

L1(A, B) = |A[0]-B[0]| + |A[1]-B[1]| + ... + |A[3071]-B[3071]|
🚕 비유 — 맨해튼 거리
뉴욕 맨해튼은 도로가 격자무늬라 대각선으로 못 가요. 가로+세로로만 이동하는 합산 거리. 그래서 이름이 "맨해튼 거리". 참고로 L2 거리는 일반적인 직선거리(피타고라스)예요.

왜 이게 "예측"이 되나?

핵심 아이디어
"비슷한 그림은 비슷한 클래스다"라고 가정합니다.
학습 데이터 안에서 픽셀 단위로 가장 닮은 1장을 찾으면, 그 라벨이 새 이미지의 라벨일 거라고 베팅하는 거예요. 단순하지만, 픽셀이 곧 의미는 아니라서 종종 틀려요. (밝기·배경에 쉽게 흔들림)

8구현 확인 (sanity check)

구현이 맞는지 빠르게 점검. 학습 데이터로 자기 자신을 예측하면, 자기 자신과 거리가 0이라 무조건 자기 라벨이 나와야 해요.

images = train_serials[:1000].astype(float)
labels = train_labels[:1000]

model = train(images, labels)
test_labels_sanity = predict(model, images[:10])

print("예측:", test_labels_sanity)
print("정답:", list(model.labels[:10]))
train_serials[:1000]
학습 데이터에서 앞쪽 1000장만 사용. 5만 전체를 쓰면 너무 느려서 작게 시작.
.astype(float)
픽셀 값을 정수(uint8)에서 실수(float)로 변환. 다음 절 ⚠️ 박스에서 설명!
model = train(...)
앞에서 정의한 함수로 모델 생성. 사실상 Model 객체에 데이터를 담아둘 뿐.
predict(model, images[:10])
학습용 첫 10장을 다시 테스트로 넣어봄 → 자기 자신이 가장 가까우니 자기 라벨이 나와야 정상.
✅ 기대 결과
예측: [6, 9, 9, 4, 1, 1, 2, 7, 8, 3]
정답: [6, 9, 9, 4, 1, 1, 2, 7, 8, 3]
두 줄이 똑같다면 distance·argmin 로직이 제대로 동작한다는 신호.
⚠️ .astype(float) 안 하면 큰일 나는 이유
원본 픽셀은 uint8 (0~255만 표현 가능한 작은 정수)입니다. 이걸로 뺄셈을 하면 음수가 0보다 작은 값으로 표현될 수 없어 200처럼 큰 값으로 둘러붙는 오버플로(overflow)가 일어나요. 예: 5 - 10이 −5가 아니라 251로 계산됨. 그래서 빼기 전에 실수로 바꿔 음수를 정상적으로 다루도록 합니다.

9테스트 데이터로 정확도 측정

이제 모델을 진짜 평가합니다. 학습엔 보지 못한 테스트 이미지를 줘서 얼마나 맞히는지.

model = train(train_serials[:5000].astype(float), train_labels[:5000])

predictions = predict(model, test_serials[:500].astype(float))

accuracy = np.mean(np.array(predictions) == test_labels[:500])
print(f"1-NN 정확도: {accuracy:.1%}")
# 결과 출력: 1-NN 정확도: 29.0%
train_serials[:5000]
학습 데이터 5천 장. 5만을 쓰면 너무 오래 걸려서 줄임.
test_serials[:500]
테스트 데이터 500장. 즉 5000 × 500 = 250만 번의 거리 계산.
np.array(predictions) == test_labels[:500]
예측 결과와 정답을 한꺼번에 자리별로 비교. 결과는 True/False 배열.
np.mean(...)
True는 1, False는 0으로 취급해 평균. 정답률 = 맞힌 개수 / 전체가 됨.
f"... {accuracy:.1%}"
f-string(포맷 문자열). 중괄호 안의 변수를 바로 끼워 출력. :.1%는 "소수점 1자리 퍼센트로 표시" — 0.29 → 29.0%.
정확도 29% — 좋은 건가?
10개 클래스 중 무작위로 찍으면 10%. 29%는 찍기의 약 3배로, 픽셀만 봐도 이 정도는 맞힐 수 있다는 뜻이에요. 하지만 우리가 보통 "잘한다"고 부르는 90%대와는 거리가 멀어요. CNN 같은 딥러닝은 같은 데이터에서 95% 이상도 가능합니다.

class_names[ground_truth[idx]]

🤔 왜 자주 틀릴까?
1-NN은 픽셀 색만 보지 모양·의미는 모릅니다. 그래서 파란 배경의 하얀 새가 파란 바다의 하얀 배와 가깝게 계산돼버려요. "배경이 비슷하면 같은 종류"라고 착각하는 게 픽셀 기반 분류의 본질적 한계예요.

11생각해보기 + 도전 과제

💬 생각해볼 질문 3개

▶ 1. pixel 거리로 이미지를 비교하는 방식의 한계는?
  • 배경에 끌려간다 — 새가 하늘 배경, 배가 바다 배경이면 비슷하다고 봄.
  • 위치·크기에 약함 — 같은 고양이라도 살짝 옆으로 옮겨지면 거리 계산이 완전히 달라짐.
  • 밝기·색조 변화에 흔들림 — 사진 한 장을 전체적으로 어둡게 하면 다른 이미지로 봄.
  • "의미"를 모름 — 픽셀의 RGB 값만 비교할 뿐, "이게 동물의 다리인지 도로의 그림자인지"는 알 수 없음.

CNN(합성곱 신경망)은 이런 한계를 깨려고 패턴·모양·계층적 특징을 학습합니다.

▶ 2. .astype(float)은 왜 필요한가요?

원본 픽셀은 uint8입니다. 0~255 사이 양의 정수만 표현 가능해요.

a = np.uint8(5)
b = np.uint8(10)
print(a - b)   # 기대: -5  /  실제: 251 (오버플로!)

이러면 거리 계산이 완전히 망가집니다. .astype(float)로 실수로 바꾸면 음수도 자연스럽게 다룰 수 있어 정상 작동해요.

▶ 3. 학습 데이터를 5,000 → 50,000으로 늘리면?
  • 정확도 — 약간 오르지만 극적이진 않음. 1-NN의 본질적 한계(픽셀 거리) 때문에 한계가 분명.
  • 속도 — 10배 느려짐. 1-NN은 예측할 때마다 모든 학습 이미지와 거리 계산을 해야 함. 학습은 거의 무료지만 예측이 비쌈.

이런 특성을 "lazy learning(게으른 학습)"이라고 불러요 — 학습은 빠르고, 예측은 무거움.

⭐ 도전 과제

L2 거리로 바꿔보기

np.abs(...).sum(axis=1) 대신 제곱 합의 제곱근(피타고라스 거리)을 써보고 정확도 변화를 비교. 
distances = np.sqrt(
    ((self.images - image)**2).sum(axis=1)
)
사실 가장 가까운 1장을 찾는 게 목적이라 sqrt는 생략해도 결과 같음(단조함수).

K-NN으로 확장

가장 가까운 1장이 아니라 K개를 보고 다수결로 결정. 
k = 5
top_k = np.argsort(distances)[:k]
top_labels = self.labels[top_k]
return np.bincount(top_labels).argmax()
K가 너무 작으면 잡음에 약하고, 너무 크면 모든 클래스가 섞여 둔감해져요.
